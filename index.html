Secure connection checklist

OAuth secrets और tokens frontend में कभी न रखें

  1. Google Cloud project और YouTube Data API v3 + Analytics API enable करें।
  2. OAuth consent screen configure करें; production में verified domain और least-privilege scopes रखें।
  3. Backend पर Authorization Code flow + PKCE/state validation लागू करें।
  4. Client secret, refresh token और access token encrypted server-side storage में रखें।
  5. Frontend केवल backend session cookie (HttpOnly, Secure, SameSite) से API proxy को call करे।
  6. Disconnect, token revocation, audit log और data retention controls दें।
